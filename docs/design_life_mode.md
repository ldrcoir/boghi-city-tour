# طراحی معماری: سه‌بخشی + آنلاین با جایگزین AI + انیمیشن‌های زندگی

## ۱) تفکیک سه بخش (درخواست: «هر کدام جدا»)

```
Menu (home)
 ├─ «ماموریت‌ها»  → panel_levels (فصل ۱ تهران، ۵۰ مرحله)  [موجود]
 ├─ «مسابقه»      → RaceSelect: سریع/حریف‌دار (AI کاراکتردار یا آنلاین)  [جدید]
 ├─ «زندگی محله»  → scenes/story.tscn: هاب اپیزودها → cutscene → مینی‌ماموریت  [جدید]
 ├─ «کارگاه»      → garage.tscn  [موجود]
 └─ «آنلاین»      → Matchmaking overlay (جست‌وجو → تایمر → AI)  [جدید]
```

پیاده‌سازی منو: دکمه‌ی «مسابقه» = همان بازی فعلی با حریف AI؛ «زندگی محله» صحنه‌ی مستقل story.tscn (تا منو کثیف نشود)؛ «آنلاین» overlay داخل منو.

## ۲) ماشین حالت آنلاین (Matchmaking FSM)

```
IDLE → SEARCHING(0..wait_s) → FOUND  → RACE_ONLINE   [وقتی سرور وصل بود]
                            → TIMEOUT → AI_TAKEOVER → RACE_VS_AI
```

- wait_s از تنظیمات کاربر: کوتاه ۸ / معمولی ۱۵ / زیاد ۳۰ ثانیه (پیش‌فرض ۱۵).
- در طول صبر، نوار «داستانی» می‌آید (خط‌های بوقی) — لودر خشک ممنوع.
- AI_TAKEOVER: حریف = اکبرِ AI با رکورد تقریبی رده‌ی کاربر (تقلب ملایم ۵٪ به نفع بازیکن تا برد لذت‌بخش باشد).
- انتقال داده‌ی آنلاین نسخه ۱: صرفاً backend placeholder — کلاس online_race.gd سیگنال found/timeout می‌فرستد؛ وقتی سرور آماده شد فقط transport سیم می‌شود. امنیت: چت آزاد ممنوع؛ فقط بوق‌کد.

## ۳) موتور کات‌سین زندگی (procedural — بدون فایل ویدیو!)

اصل: هیچ ویدیو/فریم‌انیمیشنی در APK نیست. همه‌چیز از ترکیب اسپرایت‌های موجود + Tween + دیالوگ ساخته می‌شود → هم سبک است هم چیزی برای دزدیدن ندارد.

- **StoryStage (cutscene.gd):** خیابان پروسیجرال (آسمان گرادیانی + bg_far/bg_mid موجود + آسفالت)؛ بازیگران = اسپرایت‌های side موجود با flip/bob/breathe.
- **Beats (از JSON اپیزود):** enter/exit بازیگر با جهت، move به نقطه، bounce، shake، پلک (overlay چشم)، bubble دیالوگ (dialogue.gd)، توقف برای تپ.
- **dialogue.gd:** حباب با تایپ‌رایتر RTL، اسم گوینده، تپ = رد شدن/سریع‌کردن. صدای تایپ ندارد (درس صدای زشت!).
- **story_mgr.gd:** رجیستری اپیزود + پرچم‌های داستان + «دل محله»؛ ذخیره در همان save اصلی (Globals).
- زنجیره‌ی اپیزود→گیم‌پلی: اپیزود می‌تواند `mission: {type:"taxi", level_params...}` بدهد؛ با Globals.set_meta("start_level") وارد game.gd موجود می‌شود — صفر تغییر در موتور مسابقه.

## ۴) انیمیشن‌های نسل بعد (نقشه‌ی اجرا)

| انیمیشن | روش (بدون اکت سنگین) |
|---|---|
| پلک زدن / نگاه به عقب / زور با گاز | overlay چشم روی شیشه + Tween (در game.gd حین نیترو/پرش) |
| لبخند/جشن بعد از خط پایان | حالت celebration موجود + حباب کری‌خوانی + bounce گروهی |
| شورشویی | کف‌ذرات CPUParticles + modulate براق + لرز فرچه |
| گاراژ | جرقه‌ی پرچم + چرخش مهره ابزار + دیالوگ استاد فنر |
| باران/شب | shader گرادیان + ذرات خط باران (سبک) |
| رقص با رادیو | سینوس tilt روی pivot چرخ + همگام با BPM موسیقی v4 |

## ۵) فایل‌های جدید این مرحله

```
game/scripts/dialogue.gd     حباب دیالوگ RTL تایپ‌رایتر
game/scripts/cutscene.gd     استیج کات‌سین procedural + player beats
game/scripts/story.gd/.tscn  هاب اپیزودهای زندگی محله
game/scripts/story_mgr.gd    پرچم/پیشروی/ذخیره داستان
game/scripts/asset_vault.gd  ChaCha20 + BVAULT loader (کدگذاری اکت)
game/scripts/online_race.gd  FSM آنلاین + overlay جست‌وجو + AI fallback
scripts/pack_vault.py        پکر/رمزگذار (چاچا۲۰ خالص پایتون — بدون وابستگی)
game/data/story/episode_01.json  «سیب‌زمینی و سنگک» (منبع plaintext بیرون از APK)
```
