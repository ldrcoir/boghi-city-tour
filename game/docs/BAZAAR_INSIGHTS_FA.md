## رازهای اعتیاد (جمع‌بندی برای بوقی)
1. **ماشین واقعی ایرانی + پلاک ایرانی** = هویت (دنا پلاس = خوشحالی برادرزاده!)
2. **تعمیر/لوکس‌کردن عمیق**: چراغ، استیکر، اگزوز، رنگ، ساعد
3. **دو ارز + صندوق هدیه روزانه** = دلیل برگشتن هر روز
4. **چندنفره با اسمِ خودت** = اعتیاد اجتماعی
5. گلوگاه‌هایی که از ما فرار می‌کند: نقشه/محتوای کم، تکراری‌شدن، گران‌بودن ماشین‌ها

## بازی‌های جایزه‌ی پول نقد بازار (روش کارشان)
نمونه‌ها: سلطان سکه (۶۳هزار نصب، ۴.۶)، آچمز، مینی‌منچ — همه یک الگو:
1. بازی کلاسیک ایرانی (منچ/تاس/اسکرچ/چرخ شانس) + اتاق‌های رقابتی
2. **توکن داخلی** (سکه/تیکر) که با تبلیغ هم می‌ریزد → هیچ‌وقت حذف نمی‌شود
3. **تورنمنت جایزه نقدی**: برندگان اتاق → تومان → **برداشت به کارت بانکی** (حداقل برداشت + KYC شماره کارت)
4. درآمدشان: تبلیغ ویدیویی سنگین + بسته سکه (IAP) + کسر درصد از اتاق‌ها → پول جایزه از همین‌جا می‌آید
5. ریسک: بازیِ شانس‌محور حساسیت قانونی دارد؛ بازی‌های مهارتی امن‌ترند

### برای بوقی: از این الگو فقط «هدیه روزانه + ویدیوی جایزه‌ای» را برمی‌داریم.
پول نقد واقعی به بازی کودکان نمی‌آید — ولی الگویش (برداشت درون‌بازی) برای بازی توکنی آینده‌ی ما (بخش ۱۴ GDD) نقشه‌ی راه است.
