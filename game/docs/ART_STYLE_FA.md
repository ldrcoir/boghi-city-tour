## ۳) قواعد ده‌گانه نقاشی
1. خط دور نرمِ قهوه‌ای تیره (۳ تا ۵px) — مشکی ممنوع.
2. نور همیشه طلایی گرم؛ سایه‌ها آبی-سبزِ ملایم.
3. گوشه‌ها همیشه گرد؛ هیچ گوشه تیز دیجیتالی.
4. چهره ماشین: چشم بزرگ روی شیشه، ابرو روی قاب شیشه، دهان روی جلوپنجره.
5. نسبت بامزه: کابین بزرگ‌تر از واقعی، چرخ‌های پفکی با توپ کرم.
6. بافت گواش/کاغذ ملایم؛ گرادینت صاف صنعتی ممنوع.
7. دنباله حرکت = روبان رنگی نرم، نه ذره‌های تیز.
8. هر دارایی باید در ۲ ثانیه «بوقی» تشخیص داده شود (تست هویت).
9. HUD درون‌داستانی: پلاک برای اسم، حباب برای سکه، پرچم برای جایگاه.
10. تایپوگرافی فانتزی: تیترها، دکمه‌ها و HUD فقط با فونت **لاله‌زار** (حس قصه‌ای و بازی‌گونه)؛ متن‌های بدنه و توضیحات با **وزیرمتن** برای خوانایی. فونت سیستمی مطلقاً ممنوع.

## ۴) تایپوگرافی فانتزی (v1.1 — به‌روزرسانی)
| کاربرد | فونت | مثال |
|---|---|---|
| تیتر اصلی منو، اسم شهر/فصل | لاله‌زار ۵۶ | «بوقی: تور شهرها» |
| دکمه‌ها، شمارنده‌های HUD، پلاک اسم | لاله‌زار ۲۴–۳۴ | «پرش»، «سکه ۱۲۰» |
| توضیحات ماشین، متن آموزش، لیست | وزیرمتن ۲۰–۲۲ | «متعادل و بامزه — ستاره روی کاپوت!» |

قاعده: اگر متن «صدا دارد» (چیزی که بازی فریاد می‌زند) → لاله‌زار؛ اگر «آرام توضیح می‌دهد» → وزیرمتن.

## ۶) بایدها و نبایدهای UI
- ✅ دکمه اصلی: فیروزه‌ای با لبه پایینی پهن تیره‌تر (حس اسباب‌بازی)، متن سفید.
- ✅ دکمه ثانویه: کرم با لبه طلایی، متن قهوه‌ای.
- ✅ پنل: کرم، گوشه ۲۶، دور قهوه‌ای ۵px، سایه نرم.
- ❌ UI تخت استوک، گرادینت نئون، فونت سیستمی، مشکی خالص.
